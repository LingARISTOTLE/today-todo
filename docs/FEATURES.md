# 今日待办 · 功能点完整梳理

> 本文档是「功能与规则」的权威清单，逐条列出每个模块能做什么、字段语义、默认值和边界。
> AI 操作前应先读 `SKILL.md`；遇到「这条规则是什么」时查本文档。

---

## 通用概念：任务的四类标签

每个任务（task）除标题外，有四个维度标签：

| 标签 | 字段 | 取值 | 说明 |
|---|---|---|---|
| 优先级 | `priority` | `0`(P0 紧急) / `1`(P1 高) / `2`(P2 中) / `3`(P3 低) | **默认 P2** |
| 项目 | `project` | 自由字符串，如「架构师Agent / MAF数据迁移 / 稽查虾」 | 默认空 |
| 截止日期 | `due` | `YYYY-MM-DD` | **必填，新建默认今天** |
| 性质 | `nature` | 自由字符串，如「探索类 / 交付类 / 学习类」 | 默认空 |

> 项目/性质是可自定义的自由文本，但默认候选列表存于 `settings.projects` / `settings.natures`。
> 默认候选：projects = 架构师Agent / MAF数据迁移 / 稽查虾；natures = 探索类 / 交付类 / 学习类。

其它任务字段：`done`(布尔)、`doneAt`、`goalId`(关联目标 id，可空)、`createdDay`、`createdAt`。

## 一、今日待办（`public/todo/`，路径 `/`）

### 1.1 列表视图（默认视图）

- **添加任务**：底部输入框回车提交；粘贴多行可批量添加；截止默认今天。
- **标记完成/恢复**：点任务左侧圆圈（check）。
- **删除**：点任务右侧「×」。
- **改优先级（快捷）**：点任务上的 P 标，弹出下拉选 P0–P3。
- **改标题**：双击标题进入内联编辑。
- **编辑标签弹窗**：点任务上的标签或右侧「编辑」图标，弹窗可改：标题 / 项目 / 截止 / 优先级 / 性质 / **关联中期目标**。
  - 保存时，若项目/性质不在候选列表里，会自动加入 `settings.projects/natures`。

### 1.2 统计栏 + 筛选 + 进度条

顶部四个统计项，点击即筛选（再点一次回到「全部」）：

| 统计 | data-filter | 含义 |
|---|---|---|
| 待办 | `open` | 所有未完成 |
| 今日 | `today` | **今天新增**（按 createdDay） |
| 拖延 | `late` | **逾期**（due 早于今天且未完成） |
| 完成 | `done` | 所有已完成 |

- 进度条 = 已完成 / 全部。

### 1.3 排序

点顶栏「排序」按钮循环切换，默认 `priority`：

| 模式 | 含义 |
|---|---|
| `priority` | 按优先级（P0 最前） |
| `due` | 按截止日期 |
| `created` | 按创建时间 |
| `late` | 拖延最久的在前 |
| `custom` | 自定义顺序（AI 排优先级后进入） |

### 1.4 日历视图（顶栏「日历」tab，或 `?view=cal`）

- 当月月历，**周一起始**。
- 标记：**周末**（灰「休」）、**法定节假日**（绿「休」+ 节日名）、**调休上班**（橙「班」）。
- 有截止任务的日期显示**数字角标**（共/已完成/剩余），点击某天在下方「当天任务」面板列出该天截止任务。
- ‹ › 切月；「今天」回到当月。
- 节假日数据运行时从 [holiday-cn](https://github.com/NateScarlet/holiday-cn) 拉取，断网回退内置 2026 数据（`shared/holidays.js`）。

### 1.5 关联中期目标

- 任务可关联一个 goal（`goalId`），在任务上显示目标名角标，点击跳 `/goals`。
- 编辑弹窗里「关联中期目标」下拉可选（含「不关联」）。

### 1.6 AI 排优先级（✨，可选）

- 需先在「设置」配 OpenAI 兼容 API（base/key/model，**key 只存浏览器 localStorage**）。
- 点击后调模型给未完成任务排序，结果写入 `sortMode=custom`。

### 1.7 导出

- 顶栏「导出」按钮，把未完成+已完成导出成 Markdown 到剪贴板（含标签与逾期标记）。

### 1.8 学习速记卡片

- 首页内嵌「💡 今天学了吗」卡片：一句话速记 + 连续天数；「完整记录 / 复盘 →」跳 `/learn`。

### 1.9 其它

- 主题切换（浅色/深色，默认深色，尊重系统 `prefers-color-scheme`）。
- 每 5 分钟自动刷新（多标签页数据同步）。
- 快捷：`Cmd/Ctrl+K` 聚焦输入框，`Esc` 关闭弹窗。

## 二、中期目标（`public/goals/`，路径 `/goals`）

### 2.1 目标模型

- 按**季度**组织（`quarter`，如 `2026-Q3`），顶栏 ‹ › 切季度 / 「今天」回当前季度。
- 两个维度：**内功**（能力成长）/ **战功**（交付成果）。
- 目标字段：`title`(必填)、`dimension`、`category`(分类，自由文本)、`link`(原文链接)、`status`、`note`(备注)。

### 2.2 状态

| status | 显示 |
|---|---|
| `todo` | 未开始 |
| `doing` | 进行中 |
| `done` | 已完成 |

- 维度下按 category 分组展示，顶部显示完成进度条（`已完成 / 总数`）。

### 2.3 添加 / 编辑 / 删除 / 状态切换

- 「＋ 添加目标」弹窗填维度/分类/标题/链接/状态/备注。
- 目标卡片上「状态」pill 点开即可切状态；「编辑」/「删除」按钮。

### 2.4 读书笔记 + 语音朗读（category 为「书籍阅读」时显示书本样式）

- 每本书目标下挂多条「读书笔记」章节（`docs`，每条有 `title` + `url`，url 指向飞书云文档）。
- 每章可「生成并播放」音频：server 实时抓飞书正文 → 清洗 → `edge-tts` 合成 → 存 `audio/`。
- 支持多音色（晓晓/云希/云扬…），选音色存 localStorage。
- 「⟳」按钮从飞书重新抓取正文并重新生成音频。
- 章节可展开/折叠；书本有渐变封面。

> 笔记章节（`docs`）目前只在 Web UI 管理；CLI 的 goal 命令只管理目标本身（不含笔记章节）。

## 三、今天学了吗（`public/learn/`，路径 `/learn`）

两个入口：**首页内嵌卡片**（速记）+ **独立页**（完整功能）。

### 3.1 学习日记（diary tab）

- **速记**：写一条今天学到的内容，可一天多条（`learn_entries`）。
- **月历打卡**：哪天写了会亮一个绿点。
- **连续天数**：顶部显示当前连续写了多少天（断更归零；今天还没写不算断）。
- 点某天看当天条目；可编辑/删除单条。

### 3.2 季度复盘（review tab）

- 按季度展示统计：**已学习天数 / 已过天数 / 未学习天数**。
- 列出当季所有学习条目（按日期倒序）。
- 可写/保存「季度总结」（`learn_reviews`，每季度一条）。

## 四、CLI（`src/cli.mjs`）

命令完整清单与语义见 `docs/API.md`。要点：

- 所有命令都在项目根目录执行：`node src/cli.mjs <命令>`。
- 任务用 `list` 里的 `[n]`（1 起始）或完整 id 定位。
- 目标用 `goal-list` 的 `[n]`、完整 id 或唯一标题关键词定位。
- CLI 是 AI 操作的首选入口（它内部先 `load()` 再改再 `save()`，最安全）。
